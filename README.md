# اپلیکیشن AYIO 💰📊
### مدیریت هوشمند دخل و خرج، کارت‌های بانکی و دارایی‌ها

یک اپلیکیشن زیبا، مدرن و با کاربری آسان با **Python Flet** جهت مدیریت آسان درآمدها (ورودی‌ها)، هزینه‌ها (خروجی‌ها)، کارت‌های بانکی، صندوق و محاسبه موجودی کل کنونی به زبان فارسی و تقویم شمسی.

---

## 🎨 آیکون برنامه (App Icon)

آیکون اختصاصی برنامه در مسیر زیر قرار گرفته است:
```text
assets/icon.png
```
هنگام بیلد گرفتن برای اندروید، Flet به صورت خودکار از این فایل به عنوان آیکون برنامه استفاده می‌کند.

---

## 🚀 نحوه اجرا در محیط توسعه (Local)

1. فعال‌سازی محیط مجازی:
```bash
source .venv/bin/activate
```

2. اجرای برنامه:
```bash
flet run main.py
```

## 📱 نحوه خروجی گرفتن APK برای اندروید

### روش اول: خروجی ابری خودکار با GitHub Actions (ساده‌ترین روش - بدون نیاز به نصب نرم‌افزار اضافی)
یک فایل ورک‌فلو آماده در مسیر `.github/workflows/build_apk.yml` قرار داده شده است. به محض اینکه پروژه را روی گیت‌هاب قرار دهید، در بخش **Actions** با یک کلیک فایل نصبی APK ساخته شده و لینک دانلود مستقیم در اختیارتان قرار می‌گیرد.

### روش دوم: خروجی مستقیم در سیستم لوکال
در صورتی که Flutter و Android SDK روی سیستم شما نصب باشد، دستور زیر را اجرا کنید:

```bash
flet build apk --project-name ayio --product-name "AYIO" --org com.ayio.app
```

فایل خروجی APK در مسیر زیر ساخته می‌شود:
```text
build/apk/app-release.apk
```
